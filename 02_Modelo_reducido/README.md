
# Modelo reducido bidimensional de Hodgkin-Huxley

Esta carpeta contiene los programas Python
utilizados para estudiar el sistema reducido
en las variables V y n.

Se consideran las aproximaciones:

- m = m_inf(V)
- h = 0.89 - 1.1*n

Los programas permiten calcular puntos de
equilibrio, representar nulclinas y construir
retratos de fase para diferentes valores
de la corriente aplicada.
