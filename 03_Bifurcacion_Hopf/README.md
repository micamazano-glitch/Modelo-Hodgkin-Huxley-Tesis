
# Bifurcación de Hopf

Esta carpeta contiene los programas Python
utilizados para estudiar la bifurcación de Hopf
del modelo reducido de Hodgkin-Huxley.

Se incluyen procedimientos numéricos para
aproximar ciclos límite inestables mediante
integración en tiempo inverso y representar
diagramas de bifurcación y amplitud.

El valor crítico de Hopf se obtiene mediante
un cálculo previo y se utiliza como referencia
en las representaciones gráficas.
